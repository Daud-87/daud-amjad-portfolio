( 01 ) — About

I like the parts most developers avoid — production incidents, migration edge cases, and workflows that only break for one customer.

At KK Networks I own a stack of interconnected Odoo 19 modules covering CRM, subscription billing, accounting, HR, and infrastructure/utility tracking for the company's Point-of-Presence network. Most of my week is split between two things: writing the business logic a module is supposed to have, and debugging why the version already in production doesn't have it — a stale install, a cache-only bug that never shows up locally, a computed field silently not recomputing.

I led the module-side of KK Networks' Odoo 17 → 19 migration: view syntax renames, removed API methods, and workflow changes that broke silently until someone tried to use them. I also administer the Linux servers and Git deployment pipeline the modules run on, so I'm usually the person closing the loop from bug report to fix in production.

Wander Hub AI
BSCS Final Year Project — S25BS053UCP · 2025 – 2026

An AI-powered web-based tourism assistant built to make trip planning across Pakistan simpler and more personal — smart package recommendations, an NLP chatbot, voice interaction, multilingual translation, real-time weather, and live currency conversion, all in one platform for travelers, guides, and admins. Built by Daud Amjad as a BSCS Final Year Project, advised by Mr. Jawad Hassan — covering documentation, frontend development, and AI model training.

What it does
  • KNN and K-Means models recommend travel packages by budget, destination, and travel mode (air/road) — trained and tuned as part of my AI model training role
  • NLP-powered chatbot resolves travel queries and helps shape itineraries in natural conversation
  • Speech-to-text voice input plus multilingual text translation with text-to-speech playback for foreign visitors
  • Live weather forecasting (Open-Meteo) and an instant currency converter for trip budgeting
  • Custom travel package requests, Hajj & Umrah packages, and guide booking with in-app chat
  • Role-based dashboards for User, Travel Guide, and Admin — bookings, payments, package management, and analytics
Layout & screens
  • Landing page — feature highlights, role-based Login/Sign-up (User / Guider / Admin)
  • All / Air / Road package browser with filters, ratings, and cart
  • AI Predictor — destination/budget/days/transport inputs → ranked package matches with a content-vs-price match slider
  • Translator & Chatbot panel, voice input side by side
  • Guide panel (accept/reject bookings, live chat, availability) and Admin panel (bookings, payments, package requests, revenue analytics)
  • Currency converter, weather forecast with map, and a demo payment/receipt flow
Abstract (from the final report)

Wander Hub AI is an intelligent web-based tourism assistant built to make exploring Pakistan easier. It recommends tours and packages using K-Nearest Neighbors based on budget, location, and travel mode, backed by a conversational NLP chatbot, a speech-to-text voice module, and multilingual translation for foreign visitors. Users browse destinations and packages, manage profiles, and get admin responses, while guides and admins track queries, update packages, and message users through a dedicated dashboard — making it a smart, scalable way to enhance travel in Pakistan.
