( 01 ) — About

I like the parts most developers avoid — production incidents, migration edge cases, and workflows that only break for one customer.

At KK Networks I own a stack of interconnected Odoo 19 modules covering CRM, subscription billing, accounting, HR, and infrastructure/utility tracking for the company's Point-of-Presence network. Most of my week is split between two things: writing the business logic a module is supposed to have, and debugging why the version already in production doesn't have it — a stale install, a cache-only bug that never shows up locally, a computed field silently not recomputing.

I led the module-side of KK Networks' Odoo 17 → 19 migration: view syntax renames, removed API methods, and workflow changes that broke silently until someone tried to use them. I also administer the Linux servers and Git deployment pipeline the modules run on, so I'm usually the person closing the loop from bug report to fix in production.
